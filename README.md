# Rocío Ritual

App personal de autocuidado con mascota virtual: rutinas de skincare de mañana y noche, comidas, agua, objetivos de trabajo, rachas, álbum de evolución y aventuras.

- Funciona sin conexión una vez instalada en la pantalla de inicio del iPhone.
- Los datos y las fotos se guardan solo en el dispositivo; este repositorio contiene únicamente el código.
- Copia de seguridad: Ajustes → Exportar copia.

Para actualizar la app, sustituye `index.html` (y sube la versión de `VERSION` en `sw.js`).
